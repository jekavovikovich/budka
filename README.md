# Budka - Автоматизированная конура для собаки
# спецификация оборудования:
# - контроллер ESP32(NodeMCU-32S)
# - питание блока управления и нагрузки от 220 через разделительный трансформатор 1:1(гальваноразвязка)
# - питание контролера и периферийных реле через промышленный блок питания 220 > 5
# - подогрев конуры на основе инфра-красной пленки проектной мощностью 85Вт, запаянной с двух сторон в линолеум, общая толщина 8мм
# - три датчика температуры DS18B20 с раздельной 1-Wire шиной:
# - 1 - на уровне нагревателя, аварийный с установленными порогами срабатывания
# - 2 - на уровне потолка будки - опорный для термостата для поддержания температуры
# - 3 - наружный для контроля внешней темепературы, информативный - не влияет на алгоритмы
# - датчик тока на основе ZMCT103C(контроль обрыва или короткого замыкания нагревателя, график тока для контроля деградации ИК-пленки)
# - экран 2,8" ILI9341 на TFT_eSPI библиотеке
# - энкодер механический с кнопкой, 4 клика за 1 шаг
# - управление нагрузкой через твердотельное реле(SSR на основе модуля Fotek SSR-10DA) с контролем перехода через ноль
# - аварийное электромагнитное реле(EMR на основе модуля SRD-05VDC-SL) для контроля аварийных состояний
